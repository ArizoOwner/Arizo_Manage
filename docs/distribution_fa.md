# راهنمای انتشار آریزو منیجر برای دوستان و خانواده

این راهنما برای کسی است که می‌خواهد آریزو منیجر را برای نزدیکانش آماده کند: ساختن و امضای فایل
`.apk` برای اندروید، گذاشتن نسخهٔ وب (PWA) روی یک هاست رایگان برای آیفون، و یاد دادن پشتیبان‌گیری.
هیچ سروری لازم نیست و هیچ اطلاعات مالی‌ای از گوشی کسی بیرون نمی‌رود.

> **نکتهٔ مهم:** بخش‌های بومی اندروید (پیامک، اعلان بانک، اثر انگشت، چاپ) و نسخهٔ آیفون هنوز روی گوشی
> واقعی آزموده نشده‌اند. پیش از دادن برنامه به دیگران، خودتان آن را روی یک گوشی اندروید و یک آیفون
> امتحان کنید (فهرست کامل در `docs/security.md` بخش ۷).

---

## بخش الف — اندروید: ساختن، امضا و نصب `.apk`

### ۱. ابزارهای لازم (یک بار)

| ابزار | ویندوز | مک | لینوکس |
| --- | --- | --- | --- |
| Node.js نسخهٔ ۲۴ | نصب‌کنندهٔ nodejs.org | `brew install node@24` | `nvm install 24` |
| JDK نسخهٔ ۲۱ | Temurin 21 از adoptium.net | `brew install --cask temurin@21` | `sudo apt install openjdk-21-jdk` |
| Android SDK | Android Studio یا Command-line tools | همان | همان |

اگر در ایران هستید و دانلود این ابزارها بسته است، آن‌ها را از راه VPN یا پراکسی‌ای که خودتان انتخاب
می‌کنید بگیرید. خود برنامه پس از نصب هیچ نیازی به اینترنت ندارد.

پس از نصب Android SDK، در پوشهٔ `android/` فایلی به نام `local.properties` بسازید (این فایل در git ثبت
نمی‌شود). در ویندوز:

```
sdk.dir=C\:\\Users\\<نام شما>\\AppData\\Local\\Android\\Sdk
```

در مک معمولاً `sdk.dir=/Users/<نام>/Library/Android/sdk` و در لینوکس `sdk.dir=/home/<نام>/Android/Sdk` است.

### ۲. ساختن کلید امضا (فقط یک بار، و نگهداری برای همیشه)

اندروید فقط به‌روزرسانی‌ای را می‌پذیرد که با **همان کلید** امضا شده باشد. اگر این کلید گم شود، دیگر
نمی‌توانید نسخهٔ جدید را روی گوشی‌ها نصب کنید؛ کاربران باید برنامه را پاک کنند و از پشتیبان برگردانند.

در پوشهٔ `android/` این فرمان را اجرا کنید (`keytool` همراه JDK نصب می‌شود؛ در ویندوز در PowerShell یا
Git Bash):

```bash
keytool -genkeypair -v -keystore arizo-release.jks -alias arizo -keyalg RSA -keysize 4096 -validity 10000
```

یک رمز قوی بدهید و پرسش‌های نام و سازمان را پر کنید. سپس در همان پوشهٔ `android/` فایل
`keystore.properties` را بسازید:

```
storeFile=arizo-release.jks
storePassword=رمز-فایل-کلید
keyAlias=arizo
keyPassword=رمز-کلید
```

- `keystore.properties` و `*.jks` در `.gitignore` هستند. **هرگز آن‌ها را commit یا جایی بارگذاری نکنید.**
- از `arizo-release.jks` و رمزش دو نسخهٔ پشتیبان آفلاین بگیرید (مثلاً یک فلش در کشو و یک مدیر رمز).
- اگر `keystore.properties` نباشد، ساخت بدون امضا انجام می‌شود (`app-release-unsigned.apk`) و آن فایل
  روی گوشی نصب نمی‌شود.

### ۳. ساختن نسخهٔ نهایی

از ریشهٔ پروژه، این چهار فرمان را به ترتیب اجرا کنید:

```bash
npm ci
```

```bash
npm run build
```

```bash
node scripts/check-prod.mjs
```

```bash
npx cap sync android
```

سپس در پوشهٔ `android/`؛ در ویندوز:

```bash
gradlew.bat assembleRelease
```

و در مک و لینوکس:

```bash
./gradlew assembleRelease
```

فایل نهایی: `android/app/build/outputs/apk/release/app-release.apk`. این نسخه با R8 کوچک و درهم‌سازی
شده است و فراخوانی‌های گزارش (log) از آن حذف شده‌اند.

پیش از هر نسخهٔ جدید، `versionCode` را در `android/app/build.gradle` یکی بالا ببرید (و `versionName` را
مثلاً `1.1` کنید)، وگرنه گوشی آن را به‌روزرسانی نمی‌شناسد.

### ۴. بررسی امضا

`apksigner` در پوشهٔ `build-tools` اندروید است (مثلاً `%LOCALAPPDATA%\Android\Sdk\build-tools\<نسخه>\`):

```bash
apksigner verify --verbose --print-certs android/app/build/outputs/apk/release/app-release.apk
```

باید `Verified using v2 scheme (APK Signature Scheme v2): true` و اثر انگشت SHA-256 گواهی را ببینید. آن
اثر انگشت را یادداشت کنید و به گیرندگان بدهید تا در صورت شک بتوانند فایل را مقایسه کنند.

### ۵. فرستادن و نصب روی گوشی

۱. فایل `app-release.apk` را از راهی امن بفرستید (کابل، Quick Share، یا پیام‌رسانی که به آن اعتماد
   دارید). آن را در جای عمومی بارگذاری نکنید.
۲. روی گوشی فایل را باز کنید. اندروید می‌پرسد «اجازهٔ نصب از این منبع»؛ برای همان برنامه (مثلاً Files یا
   پیام‌رسان) اجازه بدهید.
۳. Play Protect ممکن است بگوید «برنامهٔ ناشناخته». «جزئیات بیشتر ← نصب در هر حال» را بزنید؛ چون برنامه
   از فروشگاه نیامده، این هشدار طبیعی است.
۴. برنامه را باز کنید، رمز ۶ تا ۸ رقمی بسازید (رمز ۸ رقمی بسیار امن‌تر است) و در صورت تمایل اثر انگشت
   را فعال کنید.

**به‌روزرسانی:** فایل جدید (با `versionCode` بالاتر و همان کلید) را مثل بار اول نصب کنید؛ داده‌ها
می‌مانند. پیش از به‌روزرسانی یک پشتیبان `.arizo` بگیرید.

### ۶. اندروید ۱۳ به بعد: «تنظیمات محدودشده» برای پیامک و اعلان بانک

اندروید ۱۳ به بعد به برنامه‌هایی که بیرون از فروشگاه نصب شده‌اند اجازهٔ دسترسی به پیامک و اعلان‌ها را
به‌طور پیش‌فرض نمی‌دهد. خود برنامه در «ابزارها ← مرکز پیامک ← راه‌اندازی» این دو قدم را نشان می‌دهد:

۱. در آریزو دکمهٔ **«باز کردن App Info»** را بزنید. در صفحهٔ اطلاعات برنامه، منوی سه‌نقطهٔ بالا ←
   **«Allow restricted settings» (اجازه دادن به تنظیمات محدودشده)** را بزنید و با رمز یا اثر انگشت گوشی
   تأیید کنید. (اگر این گزینه دیده نمی‌شود، یک بار کلید پیامک را در آریزو بزنید تا اندروید پیام
   «تنظیمات محدودشده» را نشان دهد، سپس دوباره به App Info بروید.)
۲. به آریزو برگردید و «ثبت خودکار پیامک بانکی» یا «ثبت اعلان‌های اپ بانک» را روشن کنید. اجازه‌ها فقط
   همین لحظه درخواست می‌شوند.

نکته‌ها:
- پیامک‌های رمز پویا (OTP) و تبلیغاتی پیش از هر چیز در خود گوشی دور ریخته می‌شوند و هرگز ذخیره
  نمی‌شوند. پیامک‌های تراکنش بانکی رمزگذاری‌شده در صف می‌مانند تا شما قفل برنامه را باز کنید.
- هیچ تراکنشی خودکار ثبت نمی‌شود؛ همه در «بازبینی» منتظر تأیید شما هستند.
- شمارهٔ فرستندهٔ پیامک بانک‌ها از پیش در برنامه نیست؛ اولین پیامک هر بانک را در «صندوق» تأیید کنید.
- اعلان ثبت پیامک فقط متن عمومی دارد و مبلغی روی صفحهٔ قفل نشان نمی‌دهد.

## بخش ب — آیفون: نسخهٔ وب (PWA) بدون سرور

آیفون این برنامه را از Safari به صفحهٔ اصلی اضافه می‌کند: نه هزینهٔ اپل (۹۹ دلار)، نه TestFlight، نه
انقضای ۷روزه. داده‌ها رمزگذاری‌شده در خود آیفون می‌مانند و سایت فقط فایل‌های ثابت برنامه را می‌دهد
(بدون پایگاه داده، بدون حساب کاربری، بدون آمار).

### ۱. نکته‌های فنی پیش از انتشار

- خروجی `npm run build` در پوشهٔ `dist/` است و کاملاً ثابت است. `base: './'` در `vite.config.ts` باعث
  می‌شود برنامه از هر زیرمسیری (مثلاً `https://<نام>.github.io/arizo/`) هم کار کند.
- **HTTPS لازم است:** Service Worker (کار آفلاین) و WebAuthn (Face ID) فقط روی HTTPS کار می‌کنند. هر سه
  سرویس زیر HTTPS رایگان می‌دهند.
- مسیریابی با `#` است، پس هیچ تنظیم بازنویسی مسیر روی هاست لازم نیست.
- CSP سخت‌گیرانه داخل `index.html` است و با هر سه سرویس کار می‌کند. سرآیندی اضافه نکنید که آن را شل
  کند، و هیچ اسکریپت آمار یا «بهینه‌ساز» هاست (مثل Cloudflare Web Analytics، Rocket Loader یا Vercel
  Analytics) را روشن نکنید؛ CSP آن‌ها را مسدود می‌کند و نقض حریم خصوصی هم هست.
- پیش از هر انتشار `node scripts/check-prod.mjs` را اجرا کنید.
- آدرس سایت را بعداً عوض نکنید: داده‌های هر کاربر به همان آدرس بسته است. اگر آدرس عوض شود، کاربر باید
  از پشتیبان `.arizo` برگرداند.

### ۲. Cloudflare Pages (پیشنهادی)

۱. در dash.cloudflare.com وارد شوید ← Workers & Pages ← Create ← Pages ← **Upload assets**.
۲. یک نام بدهید (مثلاً `arizo-family`) و محتوای پوشهٔ `dist/` را بکشید و رها کنید.
۳. آدرس `https://arizo-family.pages.dev` آماده است. برای نسخهٔ جدید، همان پروژه ← Create deployment و
   دوباره `dist/` را بارگذاری کنید.

یا با خط فرمان:

```bash
npx wrangler pages deploy dist --project-name arizo-family
```

### ۳. GitHub Pages

۱. یک مخزن بسازید و **فقط محتوای `dist/`** را در آن بگذارید (نه کد منبع، نه کلید امضا).
۲. یک فایل خالی به نام `.nojekyll` کنار `index.html` بگذارید و push کنید.
۳. Settings ← Pages ← منبع را همان شاخه و پوشه بگذارید. آدرس: `https://<نام‌کاربری>.github.io/<مخزن>/`؛
   برای حساب این پروژه یعنی `https://arizoowner.github.io/<مخزن>/`.

### ۴. Vercel

```bash
npx vercel deploy dist --prod
```

بار اول نام پروژه را می‌پرسد. در تنظیمات پروژه Web Analytics و Speed Insights را خاموش نگه دارید.

### ۵. نصب روی آیفون (حدود ۱۰ ثانیه)

۱. در **Safari** (نه Chrome) آدرس سایت را باز کنید.
۲. دکمهٔ اشتراک‌گذاری (مربع با فلش رو به بالا) ← **Add to Home Screen (افزودن به صفحهٔ اصلی)** ← Add.
۳. برنامه را **از آیکون صفحهٔ اصلی** باز کنید، نه از Safari؛ داده‌های این دو از هم جدا هستند.
۴. بار اول با اینترنت باز کنید تا همهٔ فایل‌ها ذخیره شوند. از آن به بعد در حالت هواپیما هم باز می‌شود و
   قفلش باز می‌شود.
۵. در تنظیمات امنیت برنامه، Face ID را فعال کنید (اگر نسخهٔ iOS پشتیبانی کند).

**به‌روزرسانی آیفون:** پس از انتشار نسخهٔ جدید، کاربر برنامه را باز می‌کند و پیام «نسخهٔ جدید آماده
است» را می‌بیند و «بارگذاری دوباره» را می‌زند.

**محدودیت‌های آیفون:** iOS به برنامه‌های وب اجازهٔ جلوگیری از اسکرین‌شات، پاک کردن خودکار کلیپ‌بورد و
یادآور زمان‌بندی‌شده در حالت آفلاین را نمی‌دهد؛ یادآورها در نوار «تعهدات پیش رو» داخل برنامه دیده
می‌شوند. اگر برنامه مدت زیادی باز نشود و Safari فضای ذخیره را آزاد کند، فقط پشتیبان `.arizo` داده‌ها را
برمی‌گرداند؛ برای همین یادآور پشتیبان را روشن نگه دارید.

### ۶. میان‌بُر اپل برای پیامک بانک (Shortcuts)

آیفون به هیچ برنامه‌ای اجازهٔ خواندن پیامک نمی‌دهد، اما برنامهٔ «میان‌بُرها» می‌تواند متن پیامک بانک
را به آریزو بدهد. داخل برنامه در «ابزارها ← مرکز پیامک ← راه‌اندازی» همین مراحل با تصویر و دکمهٔ
«کپی نشانی» آمده است:

۱. برنامهٔ **Shortcuts** ← **Automation** ← **+** ← **Message**.
۲. در **Message Contains** یکی از کلمه‌های «برداشت»، «واریز»، «مانده»، `debited` یا `credited` را بنویسید و
   در iOS 17 به بعد **Run Immediately** را روشن کنید.
۳. کنش **Base64 Encode** را اضافه کنید و ورودی آن را **Shortcut Input** (متن پیام) بگذارید.
۴. کنش **Open URL** را اضافه کنید، نشانی کپی‌شده از آریزو (`<آدرس سایت شما>/#/sms-ingest?d=`) را بچسبانید
   و خروجی Base64 را به انتهای آن اضافه کنید.

وقتی پیامک بانک برسد، آریزو باز می‌شود. هرچه بعد از `#` بیاید هرگز به سرور فرستاده نمی‌شود؛ آریزو آن را
**پیش از هر کاری** از نوار آدرس پاک می‌کند، متن را فقط در حافظهٔ موقت صفحه نگه می‌دارد و پس از وارد
کردن رمز، آن را برای بازبینی می‌آورد. اگر قفل باز نشود، با بستن برنامه متن از بین می‌رود. پیامک‌های
رمز پویا حتی اگر از این راه برسند دور ریخته می‌شوند.

## بخش ج — پشتیبان‌گیری و گم شدن گوشی

### پشتیبان `.arizo` چیست؟

یک فایل رمزگذاری‌شده (AES-256-GCM با کلیدی که Argon2id از عبارت عبور شما می‌سازد) شامل همهٔ حساب‌ها،
تراکنش‌ها، چک‌ها، وام‌ها، فاکتورها و پیوست‌ها. بدون عبارت عبور یا «کلید بازیابی ۲۴ کلمه‌ای» هیچ‌کس، حتی
سازندهٔ برنامه، نمی‌تواند آن را باز کند. **هیچ راه بازگشت دیگری وجود ندارد.**

### روش پیشنهادی

۱. ابزارها ← **پشتیبان** ← یک عبارت عبور بلند بسازید (دست‌کم ۱۰ نویسه؛ بهتر چند کلمهٔ بی‌ربط).
۲. **کلید بازیابی** را بسازید، روی کاغذ بنویسید یا چاپ کنید و جایی جدا از گوشی نگه دارید. برنامه سه
   کلمهٔ تصادفی را می‌پرسد تا مطمئن شود درست نوشته‌اید.
۳. «ساخت پشتیبان» را بزنید و فایل را **بیرون از گوشی** بگذارید: کامپیوتر خانه، فلش، یا فضای ابری خودتان
   (فایل رمزگذاری‌شده است، پس فضای ابری محتوا را نمی‌بیند).
۴. یادآور هفتگی یا ماهانه را روشن بگذارید. برنامه روزی یک «عکس فوری» رمزگذاری‌شده هم داخل خود گوشی
   نگه می‌دارد (۵ تای آخر)، اما آن با گم شدن گوشی از بین می‌رود.

### بازگرداندن

پشتیبان ← انتخاب فایل ← عبارت عبور یا ۲۴ کلمه ← پیش‌نمایش تعدادها ← **جایگزینی** (همه چیز مثل فایل
می‌شود) یا **ادغام هوشمند** (برای هر ردیف نسخهٔ تازه‌تر می‌ماند و تکراری‌ها کنار گذاشته می‌شوند). پیش از
هر بازگردانی یک عکس فوری ایمنی گرفته می‌شود. فایل اندروید روی آیفون و برعکس هم باز می‌شود.

### اگر گوشی گم یا دزدیده شد

۱. **آرام باشید:** داده‌ها روی گوشی رمزگذاری‌شده‌اند و بدون رمز برنامه خوانده نمی‌شوند. پس از چند رمز
   اشتباه قفل زمانی فعال می‌شود، و اگر «پاک کردن پس از ۱۵ تلاش ناموفق» را روشن کرده باشید، همه چیز پاک
   می‌شود.
۲. با Google Find My Device یا Find My آیفون، گوشی را قفل یا از راه دور پاک کنید.
۳. اگر رمز برنامه کوتاه یا قابل حدس بود (مثل تاریخ تولد)، فرض کنید ممکن است شکسته شود: رمز کارت‌های
   بانکی را عوض کنید و در صورت لزوم کارت را مسدود کنید. آریزو شمارهٔ کارت را نگه می‌دارد، اما هیچ جایی
   برای رمز دوم کارت یا CVV2 ندارد؛ هرگز آن‌ها را در یادداشت‌های برنامه ننویسید.
۴. روی گوشی جدید آریزو را نصب کنید و آخرین فایل `.arizo` را با عبارت عبور یا کلید بازیابی برگردانید.
۵. یک پشتیبان تازه بگیرید.

### اگر رمز برنامه را فراموش کردید

راه بازیابی رمز وجود ندارد؛ همین است که داده‌ها را امن نگه می‌دارد. برنامه را پاک کنید (یا «پاک کردن
همهٔ داده‌ها» را بزنید)، دوباره نصب کنید و از پشتیبان `.arizo` برگردانید.
